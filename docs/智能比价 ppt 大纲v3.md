# 智采云 PPT 大纲设计 v3（产品经理审核优化版 · 13P）

> **优化原则**：站在客户视角说话，每一页回答"这跟我有什么关系、能帮我省多少钱"。
> 区分「已上线」与「规划中」功能，不画饼不误导。文案接地气，客户一看就懂。

---

## 当前版本六大问题诊断

| # | 问题 | 具体表现 | 优化方向 |
|---|------|---------|---------|
| 1 | **已有功能和规划功能混为一谈** | 防围标/串标是 V1.3 规划功能，但当前 PPT 当成已有功能重点展示，客户一试就露馅 | 明确标注「即将上线」，单独设置未来规划页 |
| 2 | **文案太技术化** | "语义向量检索"、"SKU Mapping"、"非标物料归一"——客户是采购总监不是工程师 | 全部改为大白话："不管供应商怎么叫，系统都能认出是同一种材料" |
| 3 | **缺少未来规划页** | 客户看不到产品成长性，觉得"就这些功能？" | 新增 P11 产品路线图，展示 TCO、供应商门户、三单对账等激动人心的规划 |
| 4 | **P5-P9 布局完全雷同** | 连续 5 页都是"左三卡片+右截图"，客户看到第 3 页就审美疲劳 | 交替布局方向 + 插入全宽看板页打破节奏 |
| 5 | **TCO 到厂价计算器完全缺失** | 这是客户最关心的真实比价场景（含税不含税、运费、账期），产品文档有详细设计但 PPT 没提 | 放入未来规划页作为"即将上线"的重磅预告 |
| 6 | **ROI 算账太笼统** | 只说"2%~5%降本"，没给客户算一笔具体的账 | 用实际案例：年采购额 5000 万 → 每年多赚 100-250 万纯利润 |

## P2 · 痛点 —— 用客户自己的话说他的痛

### 内容架构
| 区块 | 说明 |
|------|------|
| 标题组 | 标题 + 副标题 |
| 左红卡（痛点） | 四条具体的业务痛点——说人话 |
| 右绿卡（解法） | 四条对应的解决方案——说结果 |

### 文案

**标题**：您在采购中，**是不是经常遇到这些问题？**

**左卡 —— 🔴 采购部的四大头疼事**
1. 🛑 **翻不到去年的价格**：签过的合同锁在柜子里，去年买的钢材多少钱一吨？没人记得。
2. 🛑 **供应商报价没法直接比**：甲叫"镀锌钢管"乙叫"热镀锌管"丙叫"镀锌圆管"，其实是同一个东西，但 Excel 里对不上。
3. 🛑 **比价做三天还出错**：手动在 Excel 里对齐格式、折算含税不含税、算运费，做完三天还被领导打回来说算错了。
4. 🛑 **围标串标查不出来**：三家供应商报价差 3%，像商量好的，但你没证据。

> 底条：**后果：每年白白多花 5%~12% 的采购资金，审计时说不清楚**

**右卡 —— 🟢 智采云帮你解决**
1. ✅ **合同拖进来，价格自动入库**：PDF 或 Excel 丢进系统，10秒提取出品名、规格、单价、数量，自动建库。
2. ✅ **不管叫什么名字，系统都能认出来**：同一种材料，不管供应商怎么命名，系统自动识别归类。
3. ✅ **报价丢进来，3分钟出比价表**：多家供应商回标 Excel 一键导入，自动对齐拉平，含税不含税一键切换。
4. ✅ **超过历史价格自动亮红灯**：报价比过去贵了就告警，不怕采购员"放水"。

> 底条：**结果：采购成本直降 2%~5%，比价时间缩短 80%+**

### 界面表现
- 两列等高对比卡片，红 vs 绿强烈视觉冲击
- 每条痛点用大白话，客户读一遍就能对号入座
- 底条分别用红/绿色强调后果和结果

## P4 · 场景一 —— 合同变资产：10秒让沉睡的合同"活"过来

### 内容架构
| 区块 | 说明 |
|------|------|
| 标题组 | 场景标题 + 一句话价值 |
| 左侧：操作流程（4步） | 用"第1步~第4步"说清怎么用 |
| 右侧：系统截图 | 真实合同解析界面 |

### 文案

**标题**：场景一：**历史合同变资产，10秒建好价格库**
**副标题**：把柜子里的合同变成你下次谈判的底牌

**第1步：把合同丢进来**
> 不管是 PDF 扫描件还是 Excel 表格，直接拖进系统就行。支持单份上传，也支持打包批量导入。

**第2步：AI 自动读取关键信息**
> 系统自动识别合同里的材料名、规格型号、采购单价和数量。不用人工一条条抄，10秒搞定一份合同。

**第3步：自动归入公司材料库**
> 不管供应商叫"镀锌钢管"还是"热镀锌管"，系统自动识别是同一种东西，归到公司统一的标准名下，价格自动入库。

**第4步：按项目、按供应商，随时调取所有合同**
> 合同入库后不是堆在一起找不到——
> - 📁 **按项目看**：点进任何一个项目，立刻看到这个项目签过哪些合同、找过哪些供应商、花了多少钱。
> - 🏢 **按供应商看**：点进任何一个供应商，立刻看到他跟你们签过哪些合同、参与过哪些项目、历史合作表现怎么样。
> 
> 合同不再是一堆文件，而是**按项目和供应商双维度整理好的数字资产台账**。

### 界面表现
- **布局**：左文字（操作步骤卡片纵排）+ 右系统截图
- 每步卡片：序号圆圈 + 步骤标题（粗体） + 说明文字（灰色）
- 右侧截图：`system_screenshots/contract.png`，带圆角阴影
- 步骤卡片图标色：蓝 → 绿 → 橙 → 紫，形成视觉递进
- **第4步卡片**内嵌两个小图标条（📁 按项目 / 🏢 按供应商），突出双维度穿透的差异化卖点
