# 智能采购比价 SaaS 系统产品架构（MVP 版本）

## 一、MVP 产品定位

第一版 MVP 的目标不是一次性覆盖完整招采、履约、审批、财务对账闭环，而是先把系统最核心的数据飞轮跑通：

> 历史合同导入 → AI 结构化提取 → 材料价格库沉淀 → 招采清单控价 → 供应商回标比价 → 定标价格回写

MVP 需要优先证明三件事：

1. 企业历史合同和材料价格可以被快速结构化，形成可查询、可复用的价格资产。
2. 采购人员可以基于历史价格水位完成招标前控价和回标后横向比价。
3. SaaS 平台可以支持多个租户独立使用，第一期重点保证租户可创建、数据可隔离、企业可正常使用。

## 二、MVP 功能边界

### 本期纳入

| 模块范围 | 纳入原因 |
|---|---|
| 租户管理后台 | SaaS 系统必须支持客户开通、租户初始化、数据隔离和基础运维控制 |
| 企业 PC 端 | 采购、预算、合同管理人员的主要业务操作入口 |
| 小程序端 | 提供轻量查询和 AI 助手能力，不承担复杂业务录入和审批 |
| AI 合同解析 | 产品核心差异化能力，是材料价格库冷启动的关键 |
| 材料价格库 | 系统的数据资产核心，支撑控价、比价和 AI 问答 |
| 招采清单与回标比价 | 形成从价格库到采购决策的核心业务闭环 |

### 本期暂不纳入

| 暂不纳入功能 | 暂缓原因 |
|---|---|
| 小程序审批 | 第一版先做查询与辅助，不做移动审批流 |
| 低代码 BPM 平台 | 复杂度高，容易拉长 MVP 周期 |
| 供应商自助投标门户 | 可在 PC 回标导入跑通后再扩展 |
| TCO 到厂价复杂测算 | 属于增强型比价能力，MVP 先做含税/不含税基础对比 |
| 防围标/串标雷达 | 属于风控增强模块，需等待足够报价样本沉淀 |
| 三单合一对账 | 属于履约和财务阶段，第一版先聚焦招采前后 |
| 经营 BI 大屏 | MVP 先保留基础统计，不做复杂经营分析 |
| 私有化部署管理 | 第一版后台保留客户类型字段，完整私有化交付流程后置 |
| 租户期限与配额 | 第一版不做服务期限、账号配额、存储配额、AI 额度等商业化限制，先保证租户创建和数据隔离 |

| 个人中心 | 消息通知 | 查看系统通知、解析完成提醒、异常提醒 | P1 |
| 个人中心 | 退出登录 | 退出当前账号 | P0 |

## 六、MVP 核心业务流程

### 1. 租户开通流程

| 步骤 | 操作对象 | 关键动作 | 产出结果 |
|---|---|---|---|
| 1 | 平台运营方 | 在租户管理后台新增客户租户 | 生成租户基础档案 |
| 2 | 系统 | 初始化租户编码、数据隔离标识、基础目录、默认角色和基础字典 | 租户具备独立数据空间 |
| 3 | 平台运营方 | 初始化企业管理员账号 | 企业客户可登录系统 |
| 4 | 企业管理员 | 登录企业 PC 端，维护企业信息、组织、用户、角色、权限和业务配置 | 企业内部开始安全使用 |

### 2. 合同入库流程

| 步骤 | 操作对象 | 关键动作 | 产出结果 |
|---|---|---|---|
| 1 | 采购员/合同管理员 | 上传历史合同文件 | 生成解析任务 |
| 2 | AI 服务 | 提取合同要素和材料明细 | 形成结构化草稿 |
| 3 | 系统 | 自动匹配材料 SKU | 形成材料映射结果 |
| 4 | 采购员/合同管理员 | 人工核对并修正识别结果 | 得到可信合同数据 |
| 5 | 系统 | 保存合同并写入价格流水 | 合同库和材料价格库同步更新 |

### 3. 招采控价流程

| 步骤 | 操作对象 | 关键动作 | 产出结果 |
|---|---|---|---|
| 1 | 采购员/预算员 | 导入无价招采清单 | 生成招采清单 |
| 2 | 系统 | 自动匹配材料 SKU | 清单关联材料价格库 |
| 3 | 系统 | 调取历史价格水位 | 生成建议控制价 |
| 4 | 采购员/预算员 | 修正匹配结果和控制价 | 得到招标控价依据 |

### 4. 回标比价流程

| 步骤 | 操作对象 | 关键动作 | 产出结果 |
|---|---|---|---|
| 1 | 采购员 | 导入多家供应商报价文件 | 生成回标记录 |
| 2 | 系统 | 自动识别供应商并对齐报价明细 | 形成可比价数据 |
| 3 | 系统 | 生成平铺比价大表 | 显示最低价和异常价 |
| 4 | 采购员/采购主管 | 选择中标供应商并确认定标 | 生成定标结果 |
| 5 | 系统 | 中标价回写材料价格库 | 形成下一次控价依据 |
